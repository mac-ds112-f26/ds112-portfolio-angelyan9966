01. Quarto + R Basics

My first steps with R and Quarto

This was one of my first activities using Quarto.

I practiced basic Markdown, R chunks, functions like seq() and rep(), saving objects, and using comments in code.

At this point, I was mostly trying to understand how the .qmd file, R code, output, and the final HTML page all connect together.

Open this activity

03. Univariate Visualization

Starting with one variable

This was where I started using ggplot2 more seriously.

I worked with categorical and quantitative variables and practiced choosing between bar charts, histograms, and density plots.

I also started paying more attention to things like fill, color, labels, themes, and bin width.

geom_bar() geom_histogram() geom_density() labs()

Open this activity

04. Bivariate Visualization

Adding a second variable

This activity made visualization more interesting because I was no longer only describing one variable.

I used scatterplots, boxplots, violin plots, density plots, facets, and different versions of bar charts to compare relationships between variables.

This was also where I started thinking more about which type of graph actually makes a comparison easier to understand.

geom_point() geom_smooth() geom_boxplot() facet_wrap()

Open this activity

05. Multivariate Visualization

Adding more layers

Here I started working with more than two variables at the same time.

I used color, groups, trend lines, heat maps, and star plots to add more information to a visualization.

This activity also showed me that adding more variables does not automatically make a graph better. Sometimes it can also make the graph harder to read.

color groups heat maps star plots

Open this activity

06. Spatial Visualization

Putting data on a map

Spatial visualization was probably one of the biggest changes from the earlier activities.

Instead of only thinking about values and relationships, I also had to think about where the data are located.

I practiced interactive maps with leaflet, static maps with ggplot2, point maps, geographic boundaries, and choropleth maps.

leaflet sf geom_sf() maps

Open this activity

07. Effective Visualization

Making a graph work is not the same as making it good

This activity made me think more about what happens after I already know how to make a graph.

I practiced adding better labels and captions, writing alt text, checking color accessibility, and thinking about whether a visualization could be misleading.

I also started thinking more from the reader’s perspective: what should stand out, what information needs explanation, and what can be removed if it is distracting.

labels captions alt text accessibility ethics design

Open this activity

08. Data Wrangling

Changing the data before making the graph

This activity introduced a different part of data science: working with the data itself before visualizing it.

I practiced choosing columns, keeping certain rows, sorting data, creating or changing variables, and calculating summaries.

I also learned how group_by() can be combined with summarize() to compare different groups in a dataset.

select() filter() arrange() mutate() summarize() group_by()

Open this activity
